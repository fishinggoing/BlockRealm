## 本轮行为

- 第一人称 WASD、鼠标视角、Space 跳跃 / 水中上浮、Shift 加速、F 开关飞行（Space 上升 / Ctrl 下降）、Ctrl 水中下潜；左键挖掘、右键放置、中键攻击、C 进食、E 背包 / 合成、Q / R 切换工具、数字 1–9 / 滚轮选方块、V 种植 / 收获、T 放置 / 操作熔炉、B 建床 / 休息、F5 保存、Esc 关闭背包或暂停。9 格方块栏对应 Grass 到 Glow，Water 为第 8 格，库存为 0、不可选择或放置；滚轮跳过它。选择方块槽会退出工具选择，选中火把时右键安装火把；镐用于挖掘和攻击，放方块前切回数字槽。
- 目标使用 `ABlockWorld::TraceBlocks` 的权威体素 DDA，在 7 米范围内跳过 Air / Water，返回实体目标及相邻放置格。射线起点直接读取相机组件当前世界位置，方向直接读取 Controller 当前 control rotation，不等待 CameraManager 缓存或异步视觉网格刷新。
- 左键按住才挖掘。每个目标按材质从零计时，完成一次 `SetBlock(Air)` 才增加对应库存并播放音效；继续按住可采集下一个目标。松开、换目标 / 类型、切换材料、进入菜单、失去焦点或恢复存档都会取消当前进度。切槽或换目标后仍按住，可从零开始新的计时。
- 右键点击立即尝试放置，持续按住每 0.18 秒再尝试一次。与胶囊相交时保留 0.4 秒短缓冲，在目标格和选择槽位保持一致的条件下逐帧重试，使同时跳起 / 放置时能利用脚下腾空窗口。释放右键保留该短缓冲；换目标、换槽、菜单、失焦或存档恢复清除缓冲。
- 放置位置可为 Air 或 Water，允许固体替换水。库存不足、实体格已占用、胶囊冲突、超出可编辑范围等失败显示中文提示。只有 `SetBlock` 成功才扣除一块；每次重试重新验证库存、权威格内容及当前胶囊，失败不会扣库存。
- 胶囊半径 34 cm、半高 90 cm。放置检测计算胶囊线段至方块 AABB 的最短距离，并留 2 cm 余量，始终拒绝真正侵入角色身体的方块。世界代理为编辑格同步更新地形碰撞，视觉网格继续异步刷新。

## 飞行、水中与重力

F 的 Pressed 边沿改变独立的显式飞行请求，Released 或真实物理松开解除按键锁，长按 F 不连续翻转。`IsFlying()` 同时要求显式请求与真实 `MOVE_Flying`。活动游戏中，没有显式请求却出现的 Flying / Swimming 模式会被协调回 Falling 或专用体素水态。暂停 / 恢复保留显式请求，标题 / 新开始 / 读档清除请求；关闭飞行恢复陆地重力，清除 `bCheatFlying` 并恢复角色碰撞。

| 移动 | 常速 | Shift 加速 |
| --- | ---: | ---: |
| 陆地 | 520 cm/s | 850 cm/s |
| 明确 F 飞行 | 780 cm/s | 1450 cm/s |
| 涉水 / 游动 | 220 cm/s | 300 cm/s |

水态从 `GetBlock` 采样得到，不依赖渲染材质、碰撞网格或 PhysicsVolume。足部、腰部、胸部各采中心和四个水平偏移点，总共 15 点，三层权重分别为 0.3 / 0.4 / 0.3。水占比大于 0.06 显示水中并降低非飞行速度；深水进入专用模式阈值为 0.42，已经游动时保持至占比降到 0.06，减少水面及边缘模式抖动。仅脚部涉水仍采用普通陆地运动并减速。

专用 `MOVE_Custom / VoxelWaterMode=1` 由 `UBlockRealmMovementComponent::PhysCustom` 处理：水平流体阻力、较低加速度、空格上浮、Ctrl 下潜、浮力抵消大部分重力。闲置时约 35 cm/s 轻缓下沉；升降速度受阻力与上限约束。移动使用 CharacterMovement 的 `SafeMoveUpdatedComponent`、碰撞 impact 与 `SlideAlongSurface`，不借普通飞行状态模拟游泳，也不在角色 Tick 另外移动胶囊。出水后回到 Falling，落地后由引擎恢复 Walking；按住空格出水时沿用正常 `JumpZVelocity=620`，提供跳上高一格岸边的力度。

普通跳跃 Z 速度为 620 cm/s、陆地 GravityScale 为 1.55，理论最大抬升约 126 cm，足以跨 100 cm 方块并留下脚下放置的有效窗口。显式 F 飞行优先于水运动，进入水里的显式飞行玩家仍按飞行控制；关闭 F 后根据真实水采样恢复游动或重力。

## 水下呼吸（V10d 已运行验证）

`UBlockRealmPlayerActionsComponent::TickBreathing` 从第一人称相机格的权威 Water 状态判断头部浸水，独立于移动组件的身体涉水比例；仅脚部在水中不会扣氧气。头部入水时每活动秒消耗 1 秒氧气，总量 15 秒；耗尽后的时间每累计 1 秒造成 2 点溺水伤害。相机露头立即停止溺水计时，完全耗尽后约 3 秒恢复满氧。

呼吸读取 GameMode 活动游戏状态，E 背包和 Esc 暂停冻结剩余氧气与溺水计时；它不依赖鼠标动作就绪门禁或真实焦点，因此失焦 / 尚未释放菜单鼠标不会替仍在水下的角色暂停环境伤害。HUD 在浸水或氧气未满时显示呼吸条与剩余秒数；水下不高于 25% 显示低氧提示，耗尽显示溺水警告。

组件 `ResetState()` 恢复 15 秒氧气、清零溺水计时并清除头部浸水标记；新旅程、读档与死亡重生沿角色重置路径调用。氧气和计时属于瞬态，不保存到世界 JSON。V10d 已通过真实 Tick 水下检查并生成 `19_UnderwaterBreath.png`，覆盖涉水 / 露头、氧气消耗、E / Esc 冻结、溺水伤害和重置。时间差以已完成 Actions Tick 的时刻为基准，避免跨 Tick 顺序误差；证据为 `Deliverables/Validation/ExpandedV10d_1080/`。

## 输入、菜单和恢复

`CancelGameplayInput()` 取消挖掘及放置缓冲、停止跳跃 / 当前速度、清空移动输入，并关闭鼠标就绪门禁；保留显式飞行请求。GameMode 在切换菜单输入时调用它，角色 Tick 也处理菜单状态。进入或继续游戏后，必须观察到左右鼠标都释放，才能接受新的编辑按下事件，菜单点击不会同时挖掘地形。

V9d 修正关闭 E 背包的门禁：关闭时若左右鼠标都已释放，立即重新允许正常动作；若仍按住，则继续等到释放。综合回归已通过关闭背包后重新启用动作的断言。E 背包和 Esc 暂停均会冻结活动怪物、昼夜、作物和熔炉；背包内仍允许点击配方。

`ResetGameplayState()` 在上述取消之外重置生存状态、关闭背包、清除飞行 / 水态，恢复陆地重力和速度，清除作弊飞行并恢复胶囊碰撞；已有 `MOVE_None` 保持冻结，其余状态转 Falling。`SetWorld`、`RestoreSaveState` 与新旅程边界调用它，读档再恢复已保存生存字段。当前源码捕获位置、控制器视角、选择槽位及 9 格库存，并保存生命、饥饿、工具、木板、食物、昼夜、火把、作物、熔炉、床和重生点；`ExpandedV9d_1080` 已通过暂停冻结、F5 写盘、返回标题清理和同一进程继续恢复，尚无关闭游戏进程后逐字段比较的完整证据。不保存飞行请求、瞬时速度、背包开关或动作进度；读档后重新采水并使用普通重力，`RestoreSaveState` 还会立即刷新洞穴 / 夜间局部光，避免传送后的首帧沿用旧位置状态。

正常运行要求真实游戏 viewport 同时有焦点且为前台窗口。失焦时取消挖掘 / 放置，停止一次当前速度；持续失焦期间不给移动或升降输入，但重力与水中下沉仍运行，不通过每帧清空速度让角色悬浮。V10 呼吸同样不因失焦冻结，只有背包 / 暂停等游戏状态边界冻结。重新获得焦点后，鼠标编辑需要释放后重新按下。F、左右鼠标、空格都绑定释放事件，释放可在暂停菜单时执行。

既有 `-BlockRealmSmoke` 验证模式使用隔离存档和隐藏窗口内的合成引擎输入，只有这个开关允许跳过真实焦点检查。它不会验证 Windows / Slate 的真实 Alt+Tab、鼠标捕获或桌面设备行为；普通试玩没有这个例外。

## 生存、配方、食物与战斗源码

`BlockRealmCharacter` 与 `BlockRealmSurvival` 提供生命、饥饿、工具槽、木板与五个基础配方；`BlockRealmPlayerActions` 提供攻击、食物和掉落拾取。存档保留 version 1 和严格的 9 格 `inventory` 校验，以可选 `survival`、`placedTorches` / `placedTorchSupports`、`crops`、`furnaces`、`restPoints`、`respawnPoint` 扩展持久化，新增字段不存在时采用默认值。新角色生命 / 饥饿为 100，起始工具为木镐、石镐和 8 根火把，起始食物为 6 份；背包开关、攻击冷却、命中反馈和未凑满 4 格的树叶计数是运行期状态。

HUD 可直接调用以下 Character API：

- `GetHealth()` / `GetMaxHealth()`、`GetHunger()` / `GetMaxHunger()`（均为 `float`，初始 100）；`GetHealthPercent()` / `GetHungerPercent()` 便于进度条。
- `GetSelectedToolName()`、`GetSelectedToolDurability()`、`GetSelectedToolMaxDurability()`；`GetToolSlotCount()`、`GetToolSlot(Index, OutSlot)` 和 `SelectToolSlot(Index)` 读取 / 选择 6 格额外工具槽。`GetSelectedToolName()` 在未选工具时返回“徒手”。工具类型、数量、耐久与最大耐久进入可选存档字段，旧档缺失时使用起始工具。
- `GetCraftedPlankCount()` 读取木板计数；`GetCraftingRecipes()` 返回 `TArray<FBlockRealmSurvivalRecipe>`；`TryCraftRecipe(RecipeIndex)` 原子地扣除材料并生成木板、木镐、石镐、火把或玻璃。配方纯数据和逻辑位于 `FBlockRealmSurvivalData`，HUD 不需要实现配方规则。
- `IsInventoryOpen()` / `ToggleInventory()` 控制 E 键背包覆盖层。打开时移动、挖掘、放置暂停，仍可调用 `TryCraftRecipe`；Esc 优先关闭背包，再按一次才进入原暂停菜单。
- `ApplySurvivalDamage(Amount, Reason)` / `RestoreSurvivalHealth(Amount)` 是受伤与测试入口；`TakeDamage` 已转接到同一生命循环。

徒手挖掘沿用原材质耗时基线；木镐对石 / 辉光石 / 玻璃约 0.52 倍，石镐约 0.30 倍，其他材质也有较小加速。成功用镐挖掘消耗 1 点工具耐久并消耗少量饥饿；耐久归零自动回到徒手并提示。Q / R 选择前后可用工具，数字键 / 滚轮选方块时清除工具选择；选中火把后右键调用 `ABlockRealmTorch::TryPlace`，只在生成成功后扣除一根，失败不扣除。最后一根火把用完后按住右键不自动改为放方块；左键回收火把只返还一根，继续按住不会连带挖支撑。V9d 覆盖这些输入与库存行为，及农业、熔炉、床的实际放置、暂停冻结和恢复。
