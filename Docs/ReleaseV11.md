# V11 Git 与 ZIP 交付

2026-10-15，按用户要求提交当前工程并生成新的 Windows ZIP。此前文档中“不生成 ZIP”描述的是前一轮交付；本次以本页和 ZIP 同名的 `.verification.json` 为准。

## 内容

- Git 保存当前 C++、配置、UE 资产、原始素材、说明文档、验证与打包脚本，以及 `WorkDrafts/` 中前期分工草稿。草稿不参与编译，实际代码位于 `Source/BlockRealm/`。
- 独立包使用已经验证的 V11c Win64 Development 游戏，包含 DLSS 运行库、Visual C++ 安装包、字体与 NVIDIA 授权文件。保留整个 `Windows/` 目录，双击 `BlockRealm.exe`。
- 本次 ZIP 使用 `Tools/Pack-Portable.ps1 -IncludeWorldSave`，附带打包时的当前正式世界存档；运行日志、测试存档、旧备份和 PDB 不进入 ZIP。解压到新目录即可继续该存档，避免覆盖已有游戏目录中的进度。
- `Examples/NightCave/` 额外保存此前设置的傍晚洞穴示例及恢复说明。它是独立的完整世界快照，不会自动覆盖当前进度。
- 第三方插件与编译缓存沿用 `.gitignore`，不进入源码提交；恢复插件的方法见主 README。源码提交不包含 `Deliverables/` 和日常 `Saved/` 数据。

## 傍晚洞穴示例

完整昼夜为现实 900 秒，即 15 分钟。太阳下山后，约游戏时间 18:18 进入夜间逻辑，约 05:42 结束；标题、暂停菜单和背包会暂停时间。

示例从 17:45:36（`timeOfDay=0.74`）开始，正常游玩约 20.47 秒后进入夜晚。人物世界位置为 `[4750,-21550,2392.15]` cm，位于地表，入口在附近约 6 格。两格宽的下行通道从方块坐标 `[42,-212,20]` 通到天然洞穴 `[58,-212,4]`；深处照明依赖实际火把或荧石。此前 399 项地形编辑全部保留，新增 63 项通道编辑，原有库存和生存状态保留。玩家后来继续游玩过，ZIP 中的当前正式存档可以与此示例不同。
