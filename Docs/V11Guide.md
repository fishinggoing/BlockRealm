# 方境 V11 玩家简明指南

本轮重点是可点击的背包、独立的方块与工具选择、第一人称手持外观、采集等级、真实落地摔伤，以及猪、羊和原创岩怪。背包、合成、目标提示与挖掘进度采用较大的中文文字；长提示分行显示。

## 上手操作

| 操作 | 按键或方法 |
| --- | --- |
| 移动、观察 | WASD、鼠标 |
| 跳跃 / 水中上浮 | 空格；水中 Ctrl 下潜，Shift 加速 |
| 开关飞行 | F；飞行时空格上升、Ctrl 下降 |
| 打开背包 | E；E / Esc 或右上角按钮关闭 |
| 选择方块 | 数字 1–9 或滚轮；也可在背包点击有库存的方块 |
| 选择工具 | Q / R 循环切换可用工具与空手；也可在背包点击工具 |
| 切为空手 | 0，或在背包点击“空手” |
| 采集 | 对准方块按住左键，等待进度完成 |
| 放置 | 手持方块时按右键；手持火把时右键安装火把 |
| 攻击生物 | 对准近处生物按鼠标左键，等待攻击冷却后再次按下；中键兼容保留 |
| 进食 | C，或在背包点击食物卡片 |
| 保存、暂停 | F5 保存；Esc 暂停，背包打开时先关闭背包 |

背包点击方块、可用工具或空手后会装备并返回游戏。点击配方可以合成，右侧显示材料需求与产物；工具槽显示数量或耐久。方块与工具使用不同选择：数字键或滚轮会切回方块，Q / R 会进入工具循环。选中镐或空手时，要放方块需先选择方块槽。

九个方块槽依次是草方块、泥土、石头、沙子、原木、树叶、玻璃、水、荧石。第 8 槽水随地形生成，不能选择、采集或放置，滚轮会跳过它。背包中的空方块槽不能点击装备。

## 采集与生存

| 目标 | 最低采集要求 |
| --- | --- |
| 草地、泥土、沙块、木材、树叶 | 徒手即可；镐也可采集 |
| 岩石 | 木镐或石镐 |
| 辉光石 | 石镐 |
| 玻璃 | 石镐才能完整回收 |
| 水面、空气 | 不能采集 |

火把不能挖方块。先徒手采木材，在 E 背包把 1 木材制成 4 木板，再用 3 木板和 1 木材制作木镐；用木镐取得岩石后，以 3 岩石和 1 木材制作石镐。工具不够等级时会显示原因，不会完成采集或获得方块。镐有耐久，留意工具栏，损坏后需重新制作。

普通离地和跳跃会按途中最高点至落地的真实落差计算摔伤。前 3 格落差安全，超过部分约每格扣 10 生命，半格也按比例计算；跳起后落下会计入跳跃高度。入水、飞行以及传送 / 读档等重置边界另行处理摔落记录。高处行动前先找落脚点。

每份食物最多恢复 28 饥饿和 4 生命；两项都满时不会消耗。每成功采集 4 块树叶补充 1 份食物，也能靠近生物掉落物拾取食物。水下留意氧气提示，及时上浮。已有种植、熔炉与床操作仍分别使用 V、T、B，准星提示会显示当前能执行的动作。

## 猪、羊与岩怪

猪和羊会在附近游走、停下低头，受到攻击后逃跑，不会主动攻击玩家。左键可攻击，击败猪掉落 2 份食物，羊掉落 1 份，靠近即可拾取。当前没有繁殖、驯养或剪羊毛玩法。

岩怪的游戏内名称是“岩脊守兽”，会发现并追击附近玩家，近身攻击受墙体遮挡。击败后掉落石头和荧石。白天也可能遇见，夜间会补充更多；可用镐提高左键攻击伤害，实际命中会消耗镐耐久。附近生物采用有限数量补充，远离玩家后会清理。

## 画面与阅读

默认采用显示器原生分辨率的无边框窗口、**TSR 100% 渲染比例**，关闭动态分辨率、运动模糊与景深。标题页或 Esc 暂停菜单的“画面”区可选“原生 TSR”“DLSS 质量”“DLSS 平衡”“DLSS 性能”。DLSS 需要受支持的 NVIDIA RTX 显卡、驱动与运行环境；不可用或启用失败时回退 TSR，界面显示实际模式与提示。帧生成默认关闭。

新版背包按 Minecraft 的灰色槽位、3×9 网格、下方快捷栏和悬停说明安排。物品名称、数量、采集要求和耐久在悬停提示中显示，避免文字挤在每个格子里；界面会随窗口比例缩放，当前没有独立的字号调节项。当前仍是固定类型库存，不支持完整的自由拖放堆叠。

角色没有随身补光。天空照亮露天表面，火把、荧石和燃烧熔炉照亮附近环境；没有实际光源的地底会暗，探索前携带并放置火把。仅手持火把不会产生自动跟随光。

## 当前范围与验证状态

- 这是原创方块生存原型，尚非完整的 Minecraft 式玩法体系。可用方块有限，工具目前为木镐、石镐与火把，合成和生物行为也保持简化。
- 生物个体、位置和掉落物暂不持久化；继续游戏时重新建立附近生物，不能据此保留某一只猪、羊或岩怪。
- 当前兼容模式使用硬件光追（HWRT）Lumen **Surface Cache**；**Hit Lighting 禁用**，不能将其表述为完整 Hit Lighting 路径。
- 本轮手持与生物外观由项目代码构造原创几何，新增素材费用 **0 元**；不使用 Minecraft 的受版权保护代码、贴图、模型或音效。项目既有字体等授权来源见 [素材来源记录](AssetSources.md)。
- **最终原生 1440p 回归：267/267 通过，0 失败，26 张截图。** 背包、边缘悬停、手持和水下界面已实拍检查。光影专项与已知限制见 [V11 实测记录](V11Validation.md)；本页不作全游戏帧率或长期稳定性保证。
