# 交互 HUD 反馈

HUD 沿用 1920×1080 等比居中布局、MiSans 与原有薄荷绿配色。

- 持续挖掘时，准星下方显示「正在挖掘」、进度条、百分比及预计剩余秒数；停止挖掘后隐藏，标题和暂停菜单不绘制该面板。
- 左上角显示飞行、水中或步行，飞行时明确提示「F 关闭飞行」。底部区分 Space 跳跃、上浮或上升，Ctrl 仅在飞行或水中显示下降。
- 操作说明为「左键 按住挖掘」「右键 放置」「中键 攻击」「C 进食」「数字/滚轮切换」「E 背包」「F 开启/关闭飞行」。现有交互失败及保存提示保留。

角色接口约定：`GetMiningProgress()` 返回 0–1，`GetMiningDuration()` 返回当前总耗时（秒），并使用 `IsMining()`、`IsInWater()`、`IsFlying()` 和 `GetInteractionNotice()`。

静态检查：进度面板设计边界为 (808,606)–(1112,686)，位于准星下方 56 像素，距离快捷栏标题 221 像素；1280×720、1920×1080、1920×1200、2560×1080 的等比缩放均保留间隔。文字宽度限定于各自区域，`git diff --check` 通过。

本轮未启动 UE、构建或提交；实际游戏渲染与交互时序尚未运行验证。画面重建及 DLSS 参数未改动。

## 背包、合成与生存信息（本轮纵切片）

- 游戏中左上角新增生命与饥饿条；右上角显示当前手持工具名称和耐久条。生命、饥饿、工具信息直接读取角色的 `GetHealth()`、`GetMaxHealth()`、`GetHunger()`、`GetMaxHunger()`、`GetSelectedToolName()`、`GetSelectedToolDurability()`、`GetSelectedToolMaxDurability()`。
- 角色负责 `E` 输入并维护 `IsInventoryOpen()` 状态，HUD 只同步状态、切换鼠标/UI 输入模式，因此不会发生双重切换。背包打开时 `Esc` 先关闭背包，再交给原有暂停菜单；背包关闭后暂停菜单行为不变。
- 背包面板使用等比居中的 1920×1080 设计坐标：左侧展示 9 槽方块物品栏，右侧展示 2×2 合成格、产出格和可合成配方列表。HUD 读取角色的 `GetCraftingRecipes()`，配方按钮调用 `TryCraftRecipe(int32)`；材料不足时保留明确的「材料不足：物品 当前/需要」提示。`BlockRealmCrafting::GetCraftingRecipes()` 是同一只读配方源的兼容 facade。
- 现有准星、挖掘进度和快捷栏仍使用原位置；背包打开期间隐藏挖掘进度，避免面板遮挡反馈。面板在 1280×720 与 1920×1080 下保持相同等比缩放和安全边距。

本轮未启动 UE、构建或生成 ZIP。已有生命、饥饿、工具与合成的兼容适配保留；新增战斗显示使用 `BlockRealmPlayerActions.h` 和角色 `GetDamageFeedbackAlpha()` 的实际接口，接线后需一起编译。

## 战斗、食物与方位

- HUD 通过 `Player->FindComponentByClass<UBlockRealmPlayerActionsComponent>()` 读取食物数量、命中提示与攻击冷却，不维护第二份动作状态。组件不存在时隐藏对应面板。
- 左上生存条下方显示食物数量与「C 进食 · +28 饥饿 / +4 生命」。右下操作说明新增「中键 攻击   C 进食」。数量与原物品栏使用相同缩写方式，超过 999 时显示 `999+`。
- 命中标记使用准星外侧四段对角线，普通命中为薄荷绿，击败为琥珀色；准星上方显示组件的命中/工具损坏文字。透明度直接读取 `GetHitFeedbackAlpha()`，不在 HUD 重置计时器。
- 攻击冷却为目标名称下方的 96×3 淡条，读取 `GetAttackCooldownPercent()`，宽度与透明度随剩余冷却减小，到 0 后隐藏。命中标记和冷却不覆盖原准星、目标名称、挖掘面板或快捷栏；背包和暂停菜单打开时隐藏。
- 顶部中央显示简易 N/E/S/W 罗盘，并高亮最接近当前控制器 yaw 的方向。世界轴约定为 X+ 东、Y+ 南：yaw 0°=E，90°=S，180°=W，−90°/270°=N；俯仰不改变方向判断。罗盘显示中文「北、东、南、西」，不用底层坐标字样解释给玩家。
- 受击时读取角色 `float GetDamageFeedbackAlpha() const`（预期返回 0–1），绘制屏幕外缘 30 设计像素内的淡红渐层。效果先于信息面板绘制，中心画面与准星保持清晰；背包和暂停期间隐藏。
- 背包左侧物品网格下方增加食物说明卡，显示数量、「关闭背包后按 C 进食」、恢复量与「每采集 4 块树叶补充 1 份」。9 槽方块、工具数量统计、2×2 合成格、配方列表与点击合成逻辑沿用原实现。
