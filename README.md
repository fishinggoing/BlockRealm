# 方境 · BlockRealm

UE 5.8.3 原创单人方块探索建造原型。程序生成地形、树木、水域、地下洞穴与辉光石矿脉，可持续挖掘、放置与保存；采用原创 PBR 方块材质、动态光照、硬件 Lumen 和 NVIDIA 官方 DLSS 4.5 UE 插件。

保留完整 Windows 文件夹，双击 `BlockRealm.exe`，不需要安装 Unreal Editor。首次运行若缺少 Visual C++ 运行库，安装包内 `Engine/Extras/Redist/en-us/vc_redist.x64.exe`。当前交付为 Windows 64 位 Development 构建，使用 DirectX 12 / Shader Model 6。

2026-10-15 最新版本为 **V11**，玩家操作见 [V11 指南](Docs/V11Guide.md)，本轮最终构建、画面及回归证据见 [V11 实测记录](Docs/V11Validation.md)。新增可点击背包、第一人称手持、采集等级、摔伤、猪羊与敌对生物；背包按灰色槽位和悬停说明调整，取消角色随身补光。游戏输出在 `Deliverables/Windows/` 完整目录；本次按要求提交 Git 并生成含当前存档的新 ZIP，交付说明见 [V11 Git 与 ZIP 交付](Docs/ReleaseV11.md)。下文未标 V11 的数值与旧光影说明为历史记录，以 V11 实测记录为准。

操作：WASD 移动，鼠标观察，Space 跳跃，Shift 加速；F 开启或关闭飞行，飞行时 Space 上升、Ctrl 下降。按住左键挖掘，点击或按住右键放置；向下看并跳起可往脚下搭方块。数字 1–9 / 滚轮选择方块槽并切回方块放置；Q / R 切换工具，选中火把后右键将它装在实体表面。鼠标中键攻击，C 进食，E 打开或关闭背包并点击配方合成；V 种植 / 收获，T 放置 / 操作熔炉，B 建床 / 休息；F5 保存，Esc 关闭背包或进入暂停菜单。水中移动减速，Space 上浮并跳上岸、Ctrl 下潜；九格快捷栏中有八类可放置方块，水槽不能选择或放置，可用实体方块填水。

当前包含单人探索、区块加载与卸载、持续挖掘、连续放置、水中移动、库存和保存 / 继续；生命、饥饿、工具耐久、五个基础配方、食物恢复、近战与怪物掉落拾取、火把实体、昼夜时钟、夜间怪物、农业、熔炉、床与重生点均已接入。徒手挖掘有材料耗时与进度条（草 0.4 秒、土 0.45 秒、木头 0.75 秒、石头 1.1 秒），镐会缩短耗时，松开、换目标、切槽或暂停会清除进度。

轻量生产与营地玩法：瞄准草地或泥土上表面按 V，消耗 1 份食物种植，正常生长 120 秒后瞄准作物按 V 收获 3 份食物；瞄准实体地面上表面按 T，消耗 8 岩石建炉，再瞄准炉子按 T 投入 1 沙块和 1 木材，8 秒烧成 1 玻璃，再按 T 领取；按 E 将木材制成木板，瞄准连续两格有支撑的空地按 B，消耗 12 木板建床。安全时瞄准床按 B 设置重生点，夜间可睡至清晨并恢复 6 生命；玩家或床附近 8 米内有活怪物时拒绝休息。床失效或床边没有安全空间时，死亡重生回落世界出生点。背包与暂停菜单会冻结怪物、昼夜、作物生长和熔炉烧制。

相机没入水时有 15 秒氧气，只有脚部涉水不消耗；露头约 3 秒回满，耗尽后每秒受到 2 生命伤害。E / Esc 冻结氧气与溺水计时，HUD 显示呼吸条和低氧警告。读档 / 重生重置氧气，相关瞬态不保存；设施瞄准提示可显示作物、熔炉和床的状态与操作。

当前采用硬件 Lumen **Surface Cache 兼容路径**，保留硬件光追与 DLSS；真正 Hit Lighting 在 RTX 4060 Laptop / 驱动 566.24 上首帧崩溃，仍未通过。全局无阴影环境方向光已移除；按全高体素竖列遮蔽的天空表面补偿默认白天 1000 / 夜间 300，它不是 Lumen GI。固定机位禁灯对照只说明该夹具；近洞可导航，远洞仍黑，晨昏前景及夜间树冠、土墙远景仍偏暗。V10e 综合日志仍有 VSM 队列溢出告警，不能宣称光影和性能问题全部解决。

这是单人原型，尚无红石、流体模拟、联机、其他维度、工作台、完整物品 / 生物体系及 Minecraft 的全部内容和规则，不能将当前范围等同于已经完成其大部分玩法。农业、熔炉和床提供轻量闭环；世界高度固定 64 方块，矿脉复用辉光石，合成在背包中直接执行。

标题页和暂停页可选择原生 TSR、DLSS 质量、平衡或性能。DLSS 以官方运行时检测为准，需要兼容的 NVIDIA RTX 显卡；不可用时使用 TSR。Reflex 在支持时开启，帧生成、多帧生成与光线重建保持关闭。不能把“使用 DLSS 4.5 插件”理解为本版启用了这些全部功能。

正式存档位于 Windows 目录内的 `BlockRealm/Saved/Worlds/BlockRealmWorld.json`，迁移前请备份。F5、返回标题和菜单退出都会保存；失败保留会话，坏档保留原件并停留标题。version 1 保留世界编辑、位置 / 视角、库存，以及可选生存、工具、昼夜、火把 / 支撑、作物、熔炉、床方向和重生点；旧档缺失新增字段采用默认值。已有同一进程返回标题继续证据，跨进程逐字段恢复仍未专项验证。飞行、菜单、动作进度及氧气 / 溺水计时不保存。`-BlockRealmSmoke` 使用独立的 `Saved/ValidationWorld`。

当前参考设备上的独立包启用硬件 Lumen，并关闭全局 PSO 预热以绕过启动崩溃；正常按需创建 PSO 仍开启，首次遇到材质或效果可能出现短暂卡顿。适配与实际验证范围见 `Docs/DeliveryReport.md` 和 `Docs/DLSSIntegration.md`。

## 制作

在项目根目录的 PowerShell 7 中运行 `./Tools/Build.ps1 -Stage All -EngineRoot <UE_ENGINE_ROOT>`；也可分别执行 Editor、Content、Package 阶段。也可以设置 `UE_ENGINE_ROOT` 或 `UE5_ROOT` 后省略参数。脚本不要求固定工程路径；`-ProjectAlias` 只在旧工具不接受当前路径时使用。构建最多并行两个 action。Editor、导入、cook、运行验证需串行。

官方 DLSS 插件需要按 NVIDIA 的 UE5.8 许可和下载流程安装到项目 `Plugins/`；本仓库保留项目所需的插件描述和配置，不提交作者电脑上的插件压缩包或绝对路径。官方入口：https://developer.nvidia.com/rtx/dlss/get-started 。UE MCP Bridge 源码和可迁移使用说明见 [MCP](Docs/MCP.md)。

`./Tools/Validate.ps1 -FreshWorld -OutputName MyValidation` 从干净的隔离世界执行独立包运行检查，并输出 JSON、日志及至少六张 1080p 截图；不加 FreshWorld 时保留之前的隔离测试存档。`./Tools/Pack-Portable.ps1 -OutputFile <新ZIP路径>` 可创建便携 ZIP，并逐文件比对 SHA-256，核验游戏内容、运行库和许可；默认不附带运行存档，加 `-IncludeWorldSave` 只额外包含当前正式世界。本次 ZIP 包含该存档和单独的傍晚洞穴示例，详见交付说明。

架构、分工与状态分别保存于 `Docs/Architecture.md`、`Docs/Progress.md` 和各模块状态文件。素材使用国内小米 MiSans 与本项目原创纹理/声音，累计素材支出 **0 元**。游戏附带字体与 NVIDIA 插件许可，来源明细见 `Docs/AssetSources.md`。
