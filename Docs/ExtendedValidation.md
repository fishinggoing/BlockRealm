# 扩展运行验收

`BlockRealmExtendedSmoke.cpp` 为现有 `-BlockRealmSmoke` 的第 18 阶段增加生存玩法检查。它在 `TickInteractionSmoke()` 完成后执行，结果继续写入同一套 `BR_CHECK` 日志与最终验收报告。共 33 阶段，固定等待 8.42 秒；平台碰撞最多额外等 5 秒，标题和继续游戏各最多等 5 秒。新增阶段独立限制为 40 秒，保留原有总超时。

本次只添加该 cpp 和本说明，未启动 Unreal Engine、编译或运行。下面列的是已实现的验收逻辑；实际通过状态与截图须由根代理构建并执行后确认。

## 确定性准备

- 仅允许在保存路径包含 `ValidationWorld` 的运行验收中执行；不会使用普通玩家存档目录。
- 在出生区块 Z=52 建立独立石平台并清空上方空间，等待真实地面碰撞后放入角色与固定在前方约 200 cm 的 Mob。清理旧测试 Mob、掉落物与火把。
- 使用角色公开的 Capture→Restore 准备已知库存、食物与生命/饥饿值，使用真实相机与控制器视角。测试动作由 `FInputKeyEventArgs::CreateSimulated` 注入真实角色绑定。
- 默认关闭日夜自动推进；在 E、Esc 关闭期间启用时钟以验证暂停，并用白天正常游戏中的推进作阳性对照。夜晚只设置固定时间，不等待自然刷怪概率。两次夜间火把测试在自然首次刷新所需的 12 秒内完成。

## 覆盖项

| 路径 | 运行断言 |
| --- | --- |
| E 背包 | E 打开角色背包、显示光标及配方 hitbox；移动、左右键编辑、中键攻击、C 进食均不改变角色库存、工具与生存值；Mob 位置/生命、启用的时钟保持不变。 |
| 背包合成 | 在实际 HUD 第一条配方 hitbox 点击，消耗木材 1 并产生木板 4。 |
| Esc 暂停 | 实际 Esc 打开暂停；相同输入不改变角色、Mob 位置/生命与启用的时钟。 |
| 中键战斗 | 真实视线攻击石镐每次伤害 9、耐久减 1，命中反馈与冷却存在；冷却中再次点击不造成伤害、不消耗耐久；冷却后第二击有效。每次有效攻击前仅通过公开位置接口重置 Mob 到固定距离。 |
| 死亡与拾取 | 第三击击杀 Mob，产生真实 Stone、Glow 掉落 Actor 各 1；角色靠近后由真实拾取组件增加两种库存各 1，并移除掉落物。 |
| C 食物 | 生命/饥饿不足时实际 C 消耗 1 食物，恢复生命 4、饥饿 28；两者已满时实际 C 不消耗食物。 |
| 普通火把堆叠 | 选择工具槽 2、相机瞄准固定石支撑、按住实际右键：只生成 1 根火把，库存 8→7，持续按住不重复消耗、不生成副本。 |
| 最后一支火把 | 通过公开恢复接口准备数量为 1 的火把槽，在另一空格按住右键。放置后槽清空、选中工具为 None；继续按住不会放普通方块、消耗普通库存或销毁刚放的火把。 |
| 单文件保存 | 实际 F5 在暂停菜单保存，解析真正写入的世界 JSON，比较生命、饥饿、所有工具/耐久/数量、食物、木板、时间与两根火把及原始墙面支撑；保存目录只存在一个世界文件，没有额外生存文件或临时文件；公开 `SaveAdventure()` 同样成功。 |
| 标题→继续 | 实际 HUD 点击标题，验证火把实体移除且角色瞬态生存值重置；故意改变标题时钟后点击开始/继续。检查生命、饥饿、食物、木板、九槽库存、全部工具及耐久/数量、选中槽、时间、两根火把位置及原始墙面支撑、角色位置与视角全部恢复。 |
| 火把回收 | 继续游戏后实际左键瞄准一根恢复的火把，工具栏增加 1 根、只移除瞄准实体；保持按住时不能继续挖支撑或改变普通方块库存。 |
| 低海拔开放地表 | 最后建立 Z=17 的独立低平台并清空至世界顶端；角色所在格 ≤20、有开放天空时 `CaveFillLight` 必须关闭。 |

饥饿的正常累积扣减仅在需要跨正常游戏帧的食物/继续检查中允许 0.15 的误差；E、Esc 冻结和暂停下保存比较使用 0.01。所有工具数量、耐久与材料数量精确比较。
